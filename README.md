

# CLIP-BLIP

This project demonstrates the use of CLIP and BLIP models for:

- Zero-shot image classification using CLIP
- Image caption generation using BLIP
- Understanding image-text alignment

## Models Used
- OpenAI CLIP
- Salesforce BLIP

## Environment
- Google Colab
- PyTorch
- Hugging Face Transformers

## Results
The notebook demonstrates image classification and caption generation on sample images.
